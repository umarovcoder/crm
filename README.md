# Latta Putta CRM

Eng oson variant: Python + SQLite. Tashqi kutubxona kerak emas.

## Ishga tushirish

1. Python 3 o‘rnatilgan bo‘lsin.
2. Terminalni shu papkada oching.
3. Ishga tushiring:

```bash
python app.py
```

4. Brauzerda oching:

```text
http://127.0.0.1:8000
```

Ma’lumotlar shu papkadagi `crm.db` faylida saqlanadi.

## Asosiy imkoniyatlar

- Lead/sdelka qo‘shish, tahrirlash, o‘chirish
- Instagram username, telefon, mahsulot va kampaniya
- Bosqichlar dropdown
- Yo‘qotish sababi
- Menejer va follow-up sanasi
- Filtr va qidiruv
- Sotuv summasi
- Dashboard va conversion
- Follow-up muddati o‘tgan bo‘lsa ogohlantirish

## Keyingi bosqichlar

Instagram/Telegram leadlarini avtomatik kiritish, loginlar, bir nechta menejer va Excel import/export qo‘shish mumkin.
